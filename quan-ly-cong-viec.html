📋 Hướng dẫn setup (chỉ cần làm 1 lần)

1Mở Google Apps Script
Truy cập script.google.com → Nhấn "New project"
2Dán đoạn code này vào editor
Xoá code cũ, copy toàn bộ đoạn dưới rồi paste vào:
3Deploy thành Web App
Nhấn Deploy → New deployment
• Type: Web app
• Execute as: Me
• Who has access: Anyone
→ Nhấn Deploy → Copy URL web app
4Dán URL vào đây
